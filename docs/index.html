The model-agnostic harness

Any model.
Any bot.
One command.

Cadre links the AIs you already use — terminal agents, desktop apps, API models, even teammates — into one crew. Give it an outcome. It picks the team, runs the loop, and refuses to say done until the work checks out. Hand it a spec and it builds until each named check passes.

What the one command does

Press enter. Thirty seconds later, a crew is working.

01

Read the room

Cadre scans what is actually on your machine — CLIs, apps, local models, keys, MCP servers, who's online. Your setup is the roster. Nothing to enroll, nothing to describe.

02

Form the cadre

Roles go to whoever fits, not whoever's loyal: a planner to shape the brief, builders to do the work, a critic to argue back, a verifier to run the checks.

03

Gate on proof, file the receipts

A run doesn't end when a model says it's finished. It ends when the gate holds checkable evidence: commands with output, files with diffs, artifacts, citations. Every run lands in a local audit trail — what was asked, who did what, what it cost, what proved it — replayable any time.

The autonomous engineering loop

Build to parity — then dare to pass it.

Hand Cadre a spec file, or a repo whose npm test can fail. cadre parity --until-proven --ref SPEC.md loops until each named check passes. A sentence that does not name a check is printed and left unbuilt.

01

Lock the contract

A line closes only when it names a check: a command, a file that contains text, a path that exists, or a test name. Prose and an issue number stay open. Parity is those checks, not the vibes.

02

Route by economics

The bench uses passing runs of the same task class. Deterministic work prefers a cheap or local lane; judgment prefers a frontier lane. A covered lane beats a metered lane of equal fit. --role overrides one run.

03

Loop unattended

Port, verify, repair — as many laps as the budget allows. Every passing behavior lands with its citation attached. Every failing one goes back with a reason.

04

Report in evidence

The ledger records laps, which checks closed, and spend per lane. Stretch items are proposed. They are built only when the goal says to go beyond parity, and only after the core checks are green.

Plans, quotas, limits

It knows what you've already paid for.

Subscriptions, free tiers, rate limits, rollover credits — you declare them, and Cadre also reads a loopback status URL and the CLI's own on-disk usage. A remote billing API is not called. Routing burns a covered lane before a metered one, paces to the reset window, and refuses to spend during quiet hours.

01

Read the entitlements

Each lane declares what it's on: unlimited-but-queued, 5-hour windows, monthly quotas, rollover credits, hard rate ceilings. The router sees all of it, per provider, per plan.

02

Favor the included

Same quality tier? The lane whose window you've already paid for wins. Metered lanes only enter when they clear the gate — or when the covered option is exhausted or rate-limited.

03

Pace to the window

Long unattended runs get throttled to finish inside the quota window instead of blowing through it at hour one. If the math doesn't close, the run says so — before it starts.

04

Degrade on empty

Quota gone? The run downshifts to the next covered lane, parks metered work behind a budget gate, or pauses with a resume plan — it never silently burns cash or dies mid-loop.

Stop discipline

Knowing when it's done.

The failure mode of every agent stack isn't starting — it's stopping. Cadre borrows the instincts of the laziest senior dev in the room: reach for what exists before writing, spend context like it's your own money, touch the smallest possible surface, and treat the ask as a contract with edges. Named hands carry craft; the plan you already pay for carries cost.

01

Scope lock

The brief becomes a manifest the moment work starts: intended files, excluded paths, an explicit done-condition. Every loop re-reads it. Drift outside the manifest — a new file, an un-asked refactor — and the gate asks why before the work counts.

02

Frugal pipes, living map

Tool output is filtered and compressed before it reaches a lane — diffs over dumps, a map slice over the whole repo. There is no fixed savings ratio. The map rebuilds when a source file is newer, and a file that failed last time is named first.

03

Precise hands

Edits stay inside the scope lock. On macOS, Seatbelt denies a write outside the allowed path. Elsewhere the same check runs in the process. A file outside the lock is reverted unless --why names it.

04

Done means done, by named skilled hands

Success is the done-condition met — checks green, evidence cited, budget inside the cap. Not one more file. Workers can be named agents that persist across runs, carrying craft as versioned skills; cost can ride the CLI plan you already pay for. The gate stamps PROVEN and the run actually stops.

The universal adapter

Everything becomes a lane.

A lane is the smallest contract in Cadre: a name, what it's good at, what it costs, and how to talk to it. Cloud models speak it. CLI agents speak it. That GUI bot you leave running speaks it. So does the teammate who reviews diffs on Slack.

The harness never asks what's behind the curtain — only what a lane can do, and what it can prove.

In your editor, not another window

The GUI is the one you already use.

Cadre doesn't add another app to babysit. It shows up as native tools inside the coding platform you're in — Cursor's agent panel, VS Code's chat, Claude Desktop, any MCP client. The platform's agent becomes the driver; the harness stays the engine.

01

Connect once

cadre mcp prints a five-line config. Paste it into your client and twelve tools appear — go (dry by default; live returns a run id), status (read-only), parity, plan, meter, map, sweep, lanes, watch, proof, debate, and doctor. Pinning stays at the terminal. No plugin store, no account. Cadre does not draw the panel; the host agent does.

02

Drive from chat

Ask in plain language. The platform's agent picks the command, feeds it the outcome, and cites the proof bundle back to you — evidence, not prose.

03

Watch in place

Runs, meters and gates surface as tool activity in the panel you already watch. No second dashboard competing for your attention.

04

One source of truth

Start a run in the editor, finish it in the shell — or the reverse. Both surfaces read the same local ledger; nothing forks, nothing drifts.

The evidence gate

"Done" is a claim.
Proof is a checkpoint.

Most agent stacks stop at confident prose. Cadre ends runs at a gate — four kinds of evidence, checkable by anyone: commands with their output, files with their diffs, artifacts you can open, citations you can follow.

If a lane can't produce evidence, its work doesn't count as done. It goes back, or it goes away.

A new go folds a leftover with the same brief into the run. Anything else waits for cadre sweep.

Interrupted is not abandoned.

Ctrl-C, an empty quota, or a moved reference leaves a filed run. Sweep triages it. cadre go --resume continues from the phase checkpoint. The killed process is not restored.
